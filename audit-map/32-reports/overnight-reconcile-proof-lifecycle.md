## Mitigation Plan
- Phase 1: 先補 source-of-truth hygiene。將 named auth prompt / appendix / handoff 缺口登記為 inventory drift，並於 reconciliation docs 改用碼證 vocabulary：`queued/running/completed/active/archived`、`completed-inspectable = completed + immutable playback route`、`stopped = forbidden doc term` (`docs/closeout/final-authoritative-plan.md:169-186`, `audit-map/20-prompts/prompt-index.md:16-82`, `audit-map/01-inventory/docs-index.md:15-55`)。
- Phase 5: 補寫 proof-shell semantics copy，而非改 UI flow。將 checkpoint semester authority、blocked progression reason、reset labels 固化入 closeout/reconciliation 文案，確保 banner/provenance 詞義與 backend 一致 (`docs/closeout/final-authoritative-plan.md:257-288`, `air-mentor-api/src/lib/proof-control-plane-tail-service.ts:346-357`, `air-mentor-api/src/lib/proof-control-plane-tail-service.ts:1624-1643`)。
- Phase 7: 回填 07A/07B/07C closeout 語義，逐列對齊 ATM-07A/07B/07C：activation 雙閘控、semester walk deterministic checkpoints、late-stage blocked/elective/final-state proof、reset 二軌。待 auth prompt 補回，再將本表之 `needs-auth-source` 逐列解封 (`docs/closeout/final-authoritative-plan.md:323-371`, `docs/closeout/assertion-traceability-matrix.md:31-33`)。
